# 她的「内在」是怎么运作的

这套东西由五个插件组成，各自负责一层，合起来让她表现得像个有连续性的存在。

```
                       ┌──────────────┐
   用户消息 ──────────► │  对话主流程   │
                       └──────┬───────┘
                              │ system prompt 注入
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
  ┌─────▼─────┐        ┌──────▼──────┐       ┌──────▼──────┐
  │ 情绪 psyche│        │ 自我 self    │       │ 经验 learn  │
  │ 现在什么感受│        │ 我是谁       │       │ 我该怎么做  │
  └─────┬─────┘        └─────────────┘       └─────────────┘
        │
  ┌─────▼─────┐        ┌─────────────┐
  │ 心跳 heartbeat      │ 改写 rewrite│
  │ 没人时做什么 │        │ 我想变成什么样│
  └─────┬─────┘        └─────────────┘
        │ 写日记 / 冒气泡
  ┌─────▼─────┐
  │ 独白 mind  │
  └───────────┘
```

---

## 1. 情绪（astrbot_plugin_miku_psyche）

四个维度，随时间自然变化：

| 维度 | 范围 | 怎么变 |
|---|---|---|
| valence 心情 | -1 ~ 1 | 你说话 +0.05，一小时回归平复 |
| energy 精力 | 0 ~ 1 | 每回复一次 -0.02，自己恢复 |
| social 社交欲 | 0 ~ 1 | **没人理会上涨**，说话后骤降 0.35 |
| curiosity 好奇 | 0 ~ 1 | 自然上涨 |

注入格式：

```
[你现在的状态]
心情不错，还算精神，有点想聊天
（这是你真实的内部状态：语气要和状态一致，但不用说出数值。）
```

查看：`/状态`

---

## 2. 独白（astrbot_plugin_miku_mind）

一天随机几次，写一段内心独白到 `mind.jsonl`，有时会附一句想说的话。

---

## 3. 自我叙事（astrbot_plugin_miku_self）

每天 22:30 左右，把当天记录压缩成两段第一人称自述：

```
## 2026-11-01 23:30
今天大部分时间都挺安静的……
我好像是个容易把事情想复杂的人。
```

存进 `self.md`，保留 7 天，之后每次对话注入最近两段。

查看：`/自我`　　立刻生成：`/自我 写`

---

## 4. 经验学习（astrbot_plugin_miku_learn）

识别你的纠正语气（"太长了""别这么说""不对"），让模型总结成一条规则：

```
原始：回复超过三句就要收住
```

同一条出现 3 次才标星（已确认），注入时优先取相关的前 3 条。

查看：`/经验`　　清空：`/经验 清空`

---

## 5. 自我改写（astrbot_plugin_miku_rewrite）

她能提出改自己，但**必须你批准**。

两类申请：

- `overlay`：加一条行为准则
- `trait`：调性格参数（话量 / 主动 / 亲昵 / 正式）

```bash
/改写                 # 看待批列表
/改写 批准 1793xxxx   # 通过
/改写 拒绝 1793xxxx   # 驳回
/改写 现状            # 看当前准则和参数
/改写 回滚            # 回到上一版
```

安全阀：
- 准则上限 1200 字
- 参数强制 0~1
- 每次生效自动备份
- 待批最多 10 条

---

## 6. 心跳（astrbot_plugin_miku_heartbeat）

每 20 分钟醒一次，算一个「冲动值」：

```
urge = social*0.5 + curiosity*0.25 + 空闲时长*0.2
     × (0.6 + energy*0.6)
     + 随机(-0.12, 0.12)
```

- `urge < 阈值` → 什么都不做（大多数时候）
- `urge > 阈值` → 写一句独白进日记
- `urge > 阈值+0.18` → 同时在她桌面上冒个气泡

每天最多 10 次，防止刷屏。

查看：`/心跳`　　立刻跳一次：`/心跳 现在`

## 数据在哪

```
data/plugin_data/
├─ astrbot_plugin_miku_psyche/state.json      情绪
├─ miku_mind/mind.jsonl                       独白
├─ astrbot_plugin_miku_self/self.md           自我叙事
├─ astrbot_plugin_miku_learn/lessons.jsonl    经验
├─ astrbot_plugin_miku_rewrite/overlay.md     准则
├─ astrbot_plugin_miku_rewrite/traits.json    参数
└─ astrbot_plugin_miku_heartbeat/heartbeat.json 行动日志
```

全部是纯文本，可以直接看、直接改。

## 成本

| 模块 | 调用频率 | 每天成本 |
|---|---|---|
| 情绪 | 0（纯计算） | 0 |
| 独白 | 3 次左右 | ~0.01 元 |
| 自我 | 1 次 | ~0.01 元 |
| 经验 | 仅纠正时 | ~0.003 元/次 |
| 心跳 | 最多 10 次 | ~0.03 元 |

合计每天 **不到 0.1 元**。

---

## 调参建议

觉得她太吵 → 调低 `urge_threshold`、减少 `max_actions_per_day`
觉得她太冷淡 → 反之，或提高社交欲的上涨速率
觉得她说话不像 → 调 `traits.json` 里的 `verbosity` 和 `warmth`
